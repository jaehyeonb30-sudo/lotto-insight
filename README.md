# 로또인사이트 — Next.js 로또 통계 웹사이트

## Mac 실행
1. Node.js 20 이상 설치: https://nodejs.org/
2. 이 폴더에서 터미널을 열고 `npm install` 실행
3. `npm run dev` 실행
4. 브라우저에서 http://localhost:3000 접속

또는 `맥북에서_실행.command` 파일을 우클릭 → 열기. macOS 보안 경고가 뜨면 터미널에서 `bash 맥북에서_실행.command` 실행. **출처를 모르는 스크립트는 실행하지 말고 먼저 내용을 확인하세요.**

## 실제 서비스 배포
- 상업적 이용이 가능한 Next.js 호스팅을 선택하세요. Vercel Hobby 무료 플랜의 상업적 이용 가능 여부는 이용약관을 확인하세요.
- `.env.example`을 `.env.local`로 복사하고 `NEXT_PUBLIC_SITE_URL=https://내도메인` 설정.
- `npm run build`로 빌드 검증 후 배포.
- Google Search Console에 사이트맵 `https://내도메인/sitemap.xml` 제출.
- 개인정보처리방침, 운영자 연락처, 쿠키/광고 고지를 실제 운영 상황에 맞게 수정.
- 애드센스 승인 후 `NEXT_PUBLIC_ADSENSE_CLIENT=ca-pub-...` 입력. 현재는 **광고 스크립트만 조건부 로드**하며 실제 광고 단위는 자동 삽입되지 않습니다. 광고 단위 코드 또는 Auto ads를 승인 이후 별도 설정하세요.
- 애드센스 승인은 보장되지 않습니다. 독창적인 콘텐츠와 기능, 정책 준수가 필요합니다.

## 데이터 주의사항
- `lib/lotto.ts`는 동행복권 공개 조회 엔드포인트를 서버에서 호출합니다. 해당 엔드포인트는 변경되거나 접근이 차단될 수 있으며, 공식적으로 안정적인 개발자 API가 보장된 것은 아닙니다.
- API가 실패하면 당첨번호를 임의 생성하지 않고 오류 안내를 표시합니다.
- 현재는 **최근 최대 100회 범위** 조회와 개별 회차 조회를 지원합니다. 전체 역대 회차 DB, 주기적 수집, 사용자 계정, 자동 갱신 파이프라인은 후속 개발 대상입니다.
- `getRecent`는 회차를 날짜 기반으로 추정하므로 공개 일정 변경 시 보완이 필요합니다.
- 번호 저장은 브라우저 localStorage에만 저장되며 기기 간 동기화되지 않습니다.
- 과거 출현 통계는 당첨 예측이 아닙니다.
